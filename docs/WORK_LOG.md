## 发现的问题

- SVG 圆石使用折线而 Canvas 使用贝塞尔曲线；SVG 忽略渐变、阴影和颗粒。
- Canvas 阴影尺寸没有随预览缩放，渲染状态可能泄漏到颗粒层。
- PNG 编码返回 null 时未报错，异步导出无并发控制和统一异常处理。
- 历史栈记录重复状态，恢复调色板时选中标识不同步。
- 预览布局读取包含侧栏留白的容器宽度，存在画布挤压与比例失真风险。
- 浅色主题缺少部分颜色 Token；挂件日期为写死日期。
- README 宣称图片拖入，但当前仅实现文件选择。

## 2026-10-05 19:20：图片分析取消与清理

- 复现异步编辑冲突：图片分析等待期间选择预设配色，旧任务仍未结束，取色按钮保持禁用；旧任务之后还可能覆盖用户的新配色。新增回归在修复前失败。
- 图片分析接受 AbortSignal；新图片、手动改色、交换 / 随机配色、撤销 / 重做、分享作品载入和页面离开都会结束旧请求的等待。改色和恢复历史不再被迟到结果覆盖。
- UI 为分析设置 20 秒等待上限；超时给出缩小图片后重试提示并恢复按钮。每个任务独立清理计时器，旧任务完成不会重置新任务的忙碌状态。
- createImageBitmap 没有原生中止解码参数，因此这里立即拒绝等待，观察后续成功 / 失败并关闭迟到位图；不宣称能立即停止浏览器内部解码。Image 元素兼容路径移除源、回调和 Abort 监听，撤销对象 URL；成功取色后也释放 Image / 采样画布。
- 画布创建放入资源清理的 try/finally；即使创建画布失败，已解码位图仍会关闭。生产子目录冒烟新增真实本地 PNG 取色及撤销。
